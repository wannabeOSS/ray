# Documentation instructions

Follow the root [AGENTS.md](../AGENTS.md).

- Use relative links for repository documents and descriptive HTTPS links for external sources.
- Keep the architecture index and documentation map current when adding documents.
- Distinguish observed facts, proposed decisions, and unresolved questions.
- Record experiment device model, Android/API level, target SDK, build identifier, procedure, result, and evidence location.
- Use synthetic notification examples. Remove personal identifiers from screenshots and logs before adding evidence.
- Avoid duplicate sources of truth: link to the canonical contract, backlog, or ADR.
- Run `make docs-check` from the repository root before handing off.
