# Security and sensitive data

This is a development workspace with an initial Kotlin app and no public release or published security contact yet.

Do not put real notification content, account identifiers, credentials, signing keys, private APKs, traffic captures or unredacted device logs into issues, pull requests or committed evidence. Reproduce with synthetic data and provide the smallest safe report.

For sensitive findings, contact the project owner privately through an already established channel. A public disclosure address and response policy must be selected before release; none is invented here.

Reports should identify affected version/commit, requirement or invariant, reproduction steps, impact and suggested mitigation. Privacy leaks, unintended source actions, and overlay input interception block release until reviewed.

See the [threat model](docs/system-architecture/07-security-and-privacy.md) and [release plan](docs/system-architecture/09-delivery-and-operations.md).
